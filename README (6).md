# 🏠 Числовые домики

Интерактивная математическая игра для детей старшего дошкольного возраста (5–7 лет), направленная на изучение и закрепление состава числа в пределах первого десятка.

👉 **[Открыть и играть в браузере](https://irina-krainskaya.github.io/)**

---

### 🎯 О чём эта игра?
В увлекательной игровой форме ребёнок знакомится с составом чисел от 4 до 10. На крыше домика указано главное число, а на каждом этаже живут два числа, которые в сумме его образуют. Задача игрока — подобрать недостающего «соседа» для каждого этажа.

### ✨ Особенности тренажёра:
* **Выбор уровня сложности:** в верхней части экрана можно переключаться между домиками для чисел **4, 5, 6, 7, 8, 9 и 10**.
* **Интерактивное управление (Drag-and-Drop):** чтобы заселить этаж, нужно перетащить подходящую карточку с цифрой с правой панели в пустое окошко домика.
* **Наглядность и развитие:** красочный интерфейс помогает детям легко визуализировать состав числа, развивает логическое мышление, внимание и навыки устного счёта.
